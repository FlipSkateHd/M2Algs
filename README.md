# MASMORRA LABIRINTICA CARDIACA
Este é um trabalho feito com base no jogo One Card Maze, para fins educativos.
Tem o propósito de aplicar conhecimentos de C++ aprendidos no primeiro semestre da matéria Algoritmos e Programação do curso Ciências da Computação - Univali.

Neste labirinto, implementamos duas features novas:
- **Sistema de Mobs**:
	O jogador sobe de nível ao derrotar monstros. Porém, se enfrentar um monstro de nível superior ao seu, morrerá e terá que recomeçar a aventura do zero.

- **Sistema de senha**:
	Partes da senha podem ser adquiridas através de monges que te fazem charadas.

## Instruções do jogo
**W A S D** para se movimentar ao longo do mapa.
**R** para rotacionar de 90 em 90 graus.
**Q** para virar o mapa.
